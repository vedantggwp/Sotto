# Support

Sotto is maintained as an open-source project. Public support happens through GitHub issues and pull requests.

Use GitHub issues for:

- reproducible bugs;
- installation or packaging failures;
- permission and setup documentation gaps;
- voice command parser problems;
- focused feature requests.

Before opening an issue, please check existing issues and include your macOS version, Python version, app mode, permissions state, and a minimal reproduction when possible.

Do not post private recordings, transcripts, credentials, or sensitive local logs in public support requests.
