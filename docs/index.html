How it works

Three steps. Zero round trips.

🎤

Speak

Hold your hotkey and talk naturally. Audio stays in memory.

⌨

Transcribe

Whisper processes your audio locally with Metal GPU acceleration.

⚡

Execute

Commands run instantly. Dictation types at your cursor position.

Design Principles

Built on three constraints that make everything better

01

Nothing leaves your Mac

Audio capture, Whisper inference, and keyboard execution all happen locally. Zero network calls. Your voice data is never stored.

02

Press and speak

One hotkey. No wake words, no activation delays, no "hey Sotto." The pill overlay shows real-time audio levels while you talk.

03

Commands + dictation

30 voice commands for app switching, window management, and system control. Everything else is typed at your cursor.

Architecture

Three processes, one protocol

Tauri Shell

Rust manages windows, tray, and global shortcuts

→

React Pill

Real-time waveform, state transitions, settings UI

→

Python Sidecar

Audio capture, Whisper, intent parsing, execution

→

JSON IPC

stdin/stdout protocol, no HTTP, no sockets
